# Personal team preparation

Open `project-guide/guide.html` directly in your browser (double-click). The guide, styles, fonts and 1,200-question viva bank work locally. Starting the main app is only needed if you follow an **Open app** link.

This folder is not served by Tideway and is excluded from submission ZIPs and Docker images. It is team preparation material, separate from the product interface.

Optional content checks, from the repository root:

```
python -m unittest discover -s personal-prep/project-guide -p test_guide.py
node --check personal-prep/project-guide/guide.js
```
