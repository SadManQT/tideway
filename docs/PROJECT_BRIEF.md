# Project brief: making Tideway a winning FinTechathon 2026 entry

*English translation and restructuring of the team lead's original Bangla brief (14 October 2026).*

## Background

Our team entered the **FinTechathon 2026 International Track** (Shenzhen International FinTech Competition, theme *"AI as a Financial Participant"*) with **Topic E — SME Finance Copilot**. The current repository is a working demo built around the idea in our Bangla research roadmap (`FinTechathon_2026_Bangla_Roadmap.pdf`). The roadmap contains every competition detail: eligibility, dates, prizes, deliverables, the published scoring split (task completion 40%, security and compliance 30%, innovation and interaction 30%), previous winners, our idea scores, the architecture, the security model, the evaluation plan and an eight-day build plan.

The demo works, but it was built as a demo. The goal now is to turn it into a project that can win.

## What I am asking for

1. **Read the roadmap PDF thoroughly** and use it as the source of truth for the competition rules and deliverables.
2. **Research what a winning project looks like** for this competition and topic, using as much time and depth as needed. Look for useful, creative and unique features and upgrades: competitor products, agentic-payment standards, AI-agent security research, the SME market context and what these judges are likely to value.
3. **Rename the project.** The current name, *Probaho* (প্রবাহ, "flow"), is Bangla. This is an international competition, so choose a strong **single-word English name** and apply it everywhere.
4. **Make the whole project English**: code, user interface, assistant replies, documentation, slides and evidence. No Bangla text should remain in the product.
5. **Rename the GitHub repository** to the new name.
6. **Create a new folder on my computer** with the new name and put the project there, so I can keep working on it.
7. **Add every valuable feature that the research supports**, implemented and tested. Change the files directly so the team can continue from them.
8. **Update the roadmap PDF**: translate it fully into English, apply the new name and include the new features and updated plan.
9. **Translate this brief into English** and organise it clearly (this document).

## Constraints

- The submission deadline is **20 October 2026, 23:59 Beijing time (21:59 Bangladesh time)**. Our internal target is 19 October, 20:00 Bangladesh time.
- Everything runs in a **synthetic sandbox**. No real bank, lender, supplier, customer or money movement may be connected or implied.
- Claims must stay honest: no invented user results, accuracy figures, partnerships or certifications.
- Runtime code should remain easy to run for judges (Python standard library; no paid service required for the demo).
- Security is 30% of the score, so every new capability must keep the approval, scoping and evidence guarantees intact.

## Definition of done

- The new name appears consistently in the repository, UI, documents and PDF.
- No Bangla text remains in code, UI, prompts or generated documents (except this note about the original name).
- New features are implemented, covered by automated tests and visible in the demo.
- The English roadmap PDF is regenerated with the new name, features and plan.
- The project lives in a new local folder named after the project, ready for the team to continue.
- Remaining manual steps (repository rename permissions, registration, user interviews, the video) are listed clearly for the team.
